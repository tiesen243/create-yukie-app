# Create Yukie App

## The Stack

This stack is a web development stack focused on **simplicity**, **modularity**, and **full-stack typesafety**. It consists of:

- [Next.js](https://nextjs.org/)
- [ElysiaJS](https://elysiajs.com/)
- [Tailwind CSS](https://tailwindcss.com/)
- [TypeScript](https://www.typescriptlang.org/)
- [Prisma](https://www.prisma.io/)

## Getting Started

To create a new Yukie app, run:

**NPM**

```bash
npm create next-app@latest --example https://github.com/tiesen243/create-yukie-app
```

**Yarn**

```bash
yarn create next-app@latest --example https://github.com/tiesen243/create-yukie-app
```

**PNPM**

```bash
pnpm create next-app@latest --example https://github.com/tiesen243/create-yukie-app
```

**Bun**

```bash
bun create next-app@latest --example https://github.com/tiesen243/create-yukie-app
```
